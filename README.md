# 🎬 Studio Anda — Platform Streaming Video PERCUMA

Template OTT (Over-The-Top) yang lengkap dan siap guna dalam bahasa Melayu. Untuk membuat platform streaming video sendiri dengan **konten PERCUMA & Creative Commons**.

**Disclaimer:** Laman ini hanya untuk menyiarkan kandungan yang bebas royalti atau Creative Commons. Semua konten dalam platform ini mestilah legal dan licensed dengan betul.

---

## ✨ Features

- 🌙 Dark theme moden & responsif (mobile-friendly)
- 💰 Pricing plans (Percuma + Premium) — optional
- 🎯 Content grid dengan video cards
- 📢 Sponsor/iklan slot untuk monetisasi
- 🔐 Placeholder untuk user authentication
- 🌐 Bahasa Melayu (mudah di-customize)
- 📱 Fully responsive design

---

## 🚀 Setup Cepat

### 1. Clone atau Download
```bash
git clone https://github.com/yusarmy/Yusarmy.git
cd Yusarmy
```

### 2. Edit Kandungan
Buka `index.html` dan gantikan:
- **Nama Studio** — Tukar "Nama Studio Anda" dengan nama anda
- **Logo & Warna** — Ubah gradient warna dalam `<style>`
- **Video Links** — Gunakan link dari Creative Commons (lihat bawah)
- **Thumbnail** — Gantikan gambar dengan thumbnail dari video
- **Harga** — Boleh tukar ke model 100% percuma atau keep subscription

### 3. Upload ke Internet
Lihat bagian [Deployment](#deployment) di bawah.

## 💡 Strategi Konten Percuma (5 Model)

### Model 1: **Documentary Curation** ⭐
Kumpulkan dokumentari & filem public domain dalam satu tempat
- ✅ Archive.org punya ribuan
- ✅ Audience suka educational content
- ✅ Zero licensing cost

### Model 2: **Lifestyle & Nature**
Guna Pixabay + Pexels video, tambah narration anda sendiri
- ✅ Evergreen content (sentiasa relevan)
- ✅ Beautiful visual
- ✅ Great untuk beginners

### Model 3: **Educational Streaming**
Kumpulkan dari Khan Academy, TED-Ed (check license!)
- ✅ Niche audience
- ✅ Easier to monetize later

### Model 4: **User-Generated Content (UGC)**
Terima submission dari creators, revenue share model
- ✅ Infinite content supply
- ✅ Creator economy friendly

### Model 5: **Hybrid Approach**
80% free content (CC/public domain) + 20% premium nanti
- ✅ Start percuma, grow audience
- ✅ Invest dalam licensed content kemudian
